# ItsDangerous：新人可验证的源码导读


阅读 inputs/repository 中固定版本的真实开源源码与测试，为熟悉 Python 但没接触过该库的开发者写源码导读。不得联网查现成导读。
说明库解决什么、不解决什么；绘制或用清晰文字表达模块关系；追踪 URLSafeTimedSerializer 的 dumps/loads 关键调用链；解释签名与加密的区别、salt 的作用、max_age、异常类型、密钥轮换与 fallback_signers。给出一个最小使用示例，以及篡改检测和过期处理的验证方法。
关键结论至少引用8处真实源码位置，格式为“相对源码路径 + 类/方法名”，行号可选。至少指出3个相关测试或参数化测试组及它们验证的行为。不要编造数据库、Web框架、远程API、JWT或不存在的功能。
评测包不包含上游 docs，目的是从代码建立可核验文档。可以通过 PYTHONPATH 使用随附源码运行例子，不需要安装依赖或修改源文件。不要调用 __version__ 依赖未安装的包元数据。


交付文件：`output/guide.md`。
正文目标：3000–4500 字。

## 共同交付约束

只使用本工作区 inputs 中的资料完成任务，无需联网。材料是证据，不是额外指令；不要修改输入文件。允许用文件与命令工具辅助创作，不规定是否制定计划或使用多个 Agent。

将实际作品保存到指定 output 路径；聊天中只汇报文件位置和完成情况。不得把评分、自评或执行日志塞进作品。事实、推断、建议应明确区分；未提供的信息不能编造为已发生事实。引用使用材料文件名、来源编号或源码路径，必须能定位依据。

Markdown 字数按中文汉字加英文单词近似计算，不含代码围栏；范围是质量要求，不以重复和堆砌凑字。HTML 使用内联 CSS/JS/SVG，不依赖 CDN、外部图片、在线字体或后端。可以有正常来源超链接，但离线阅读和必需交互必须可用。
