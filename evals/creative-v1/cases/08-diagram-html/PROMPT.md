# 一页看懂文档发布系统：五种图解


依据 inputs 中的发布系统事实，制作一份离线中文图解网页。用同一个业务案例分别画：架构图、发布流程图、上线时间线、数据概览信息图、同步发布与异步发布概念对比图。
每种图必须承担不同的解释任务，不要用五张文字卡片冒充五种图。架构展示组件与方向；流程展示判断和失败回路；时间线区分已完成与计划；信息图体现数据口径；概念对比展示差异与适用条件。
主要信息通过SVG或HTML/CSS图形表达，辅以简短图例与解释。避免箭头乱穿、重叠、细小文字和长段说明。提供五类图的页面内导航，手机窄屏可通过重排、局部缩放或标明的图内滚动阅读，不能让整页横向失控。所有图形和文字必须离线加载；不需要炫技动画或第三方图库。


交付文件：`output/index.html`。

将实际作品保存到指定 output 路径；聊天中只汇报文件位置和完成情况。不得把评分、自评或执行日志塞进作品。事实、推断、建议应明确区分；未提供的信息不能编造为已发生事实。引用使用材料文件名、来源编号或源码路径，必须能定位依据。

Markdown 字数按中文汉字加英文单词近似计算，不含代码围栏；范围是质量要求，不以重复和堆砌凑字。HTML 使用内联 CSS/JS/SVG，不依赖 CDN、外部图片、在线字体或后端。可以有正常来源超链接，但离线阅读和必需交互必须可用。
