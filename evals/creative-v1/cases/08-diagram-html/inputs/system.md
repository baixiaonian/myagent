# V1：原创虚构文档发布系统，冻结于2026-09-18

组件：编辑端、发布API、元数据库、原文件存储、任务队列、解析Worker、检索索引、检索与下载API、阅读端。部署数量未提供，不应虚构分布式集群规模。
发布API校验身份与表单，保存原文件与“待处理”元数据，再排队。排队失败须保留失败状态并反馈，不能宣称成功发布。Worker消费任务、读取原文件、解析内容、写检索索引、更新发布状态。读者查找通过检索API查索引；下载原文件必须先检查权限，不能从搜索结果直接泄露不受控存储地址。
每个处理任务初始尝试失败后最多重试2次；再失败进入人工处理，管理员核查后可创建新的重试任务。只有解析与索引更新完成才算发布成功。审核未通过不进入发布执行。
同步方案在请求内完成处理，响应可表示处理结果，但耗时长且更易受请求超时影响；异步方案返回已接收，后续查状态或接收通知，增加队列/幂等/观测复杂度。两种方案都需要权限与失败处理。
