# 看得见的 JavaScript 事件循环


面向刚学会JavaScript函数和Promise的学生，制作一个离线中文教学演示网页，帮助他们理解同步代码、微任务和定时器任务的执行顺序。
使用随附两个固定示例，展示代码高亮位置、调用栈的教学投影、任务队列、微任务队列和输出区。提供单步、自动播放、暂停、重置和切换示例；说明这是确定性的教学模拟，不声称还原浏览器引擎内部的全部实现。
每步让学生看得出发生了什么和为什么。补充“先预测再运行”的练习与反馈，解释0ms定时器不等于立即执行、微任务会在相应检查点持续排空，以及不能从这个示例推断每轮都必定绘制。
页面默认不自动播放，手机和桌面均可读，键盘能操作，不使用实际事件竞态驱动演示结果。不要要求联网加载框架。


交付文件：`output/index.html`。
