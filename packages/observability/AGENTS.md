# 观测规则

缓存命中按实际缓存输入/已知缓存字段的输入总量加权；缺失字段及旧匿名汇总单列未知，不补零、不平均单次百分比。离线公共前缀验证不等于服务商命中或账单节省。

继承 [包约定](../AGENTS.md)。本模块只依赖 contracts，承载中立端口、区间合并与定点计价。OTel SDK、HTTP、文件、数据库放在 adapters，生命周期与查询协调放在 application。

每次实际模型请求只记一次；usage 缺失不能补零或用容量估算替代。缓存与推理子集不能重复计费；价格绑定请求开始时版本，货币分开累计。

默认 Trace 只有元数据。原始正文只由独立本机调试接口读取，不能放入普通历史、日志、SSE、OTLP 或 Agent 工具。异常不能改变执行语义，不伪造恢复、重试、完成时刻或远端内部 Span。细节见 [观测协议](../../docs/protocols/observability-v12.md)。
