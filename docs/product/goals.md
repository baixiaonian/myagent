# 产品目标

## 当前交付：本地 Web 聊天 v1

面向希望连接自有模型的个人用户，提供独立安装、持续保留本地历史的文字问答产品。用户通过页面设置接口、模型和密钥，管理多个会话，使用流式回答、停止、重新生成与 Markdown。首次使用无需修改代码。

当前边界是可信本机、单用户、自带密钥。只有 Web 客户端和本地后端，不提供账号、公共配额、收费、多租户、公网服务、图片、附件、联网搜索、知识库、工具调用、多 Agent。没有隐含的自动模型重试或摘要费用。

验收要求覆盖实际 HTTP 流与浏览器交互、持久化与并发语义、凭证隔离、打包启动和运维说明。真实服务商的多轮问答需要有效用户配置单独验收，模拟模型仅用于工程测试。

## 长期目标设计

原始 [架构设计](../../agent-architecture.html) 仍是功能完整 Agent 的方向：稳定内核、明确状态归属、受控执行、可扩展内容和编排。v1 先提供零工具、单模型调用的最小内核路径，为后续迭代留下接口。工具系统和任务验收不能通过占位返回假装已经实现。
