# 产品目标

## 当前交付：本地 Web Agent 与工具执行

面向希望连接自有模型的个人用户，提供独立安装、持续保留本地历史的文字问答产品。用户通过页面设置接口、模型和密钥，管理多个会话，使用流式回答、停止、重新生成与 Markdown。首次使用无需修改代码。支持 Responses / Chat Completions，模型可自主操作绑定工作区的文件、受控命令和经批准的 MCP 工具；过程、结果和可选计划随对话保存。

当前边界是可信本机、单用户、自带密钥。只有 Web 客户端和本地后端；已支持本机轻量多 Agent 团队、扩展能力与文档工作区，不提供账号、公共配额、收费、多租户、公网服务、图片输入、附件、内置联网搜索或知识库。不自动重试模型请求；上下文接近容量时使用当前模型整理历史，并明确展示额外请求与用量。

验收要求覆盖实际 HTTP 流与浏览器交互、持久化与并发语义、凭证隔离、打包启动和运维说明。真实服务商的多轮问答需要有效用户配置单独验收，模拟模型仅用于工程测试。

## 长期目标设计

原始 [架构设计](../../agent-architecture.html) 仍是功能完整 Agent 的方向：稳定内核、明确状态归属、受控执行、可扩展内容和编排。当前使用统一自主循环，工具执行与上下文经可替换端口扩展，不限制模型必须遵循规划或反思流程。工具系统和任务验收不能通过占位返回假装已经实现。

项目体验：用户直接开始 Agent 任务，不必先建立工作区记录；可选择本机项目，默认任务也有独立目录。MCP 设置同时支持表单与文件，真实展示服务和工具状态。

长期记忆 v1 支持用户显式开启后的空闲提炼、跨会话查阅和人工纠正。后台模型请求单独记录额度与用量；无需新增会话笔记。已保存正文可在独立设置页查看、编辑、遗忘和撤销。
