# 产品目标

需求负责人：白鑫磊。

## 服务对象与任务

面向个人和小团队的通用工作 Agent，能够持续处理编码、资料研究和文档产出。用户提交目标与约束，Agent 使用模型和工具推进任务，必要时接收补充或授权，最终交付可检查、可追溯的产物。

## 完整产品的目标能力

- 流式对话、多模型、附件与工作区。
- 工具执行、受限环境、MCP 与业务连接器。
- 上下文预算、历史压缩、来源检索、长期记忆。
- Skill、Hook、Plugin 的受控扩展。
- 任务计划、固定 Workflow、后台与定时工作、多 Agent 委派。
- 人工介入、取消、断线重连、崩溃恢复、版本化产物。
- 用户 / 工作区权限、凭证隔离、观测与任务质量评测。

这些是目标范围，实际进度以 [当前状态](../STATUS.md) 为准。

## 设计取舍

初始采用本地 / 单实例模块化单体，保留模型、执行和存储的替换接口。Web 为主要工作台，CLI / SDK 复用同一应用协议。优先清晰边界和可验证结果，按具体需求增加实现与依赖。

## 完成的含义

模型停止输出、一次 Run 正常结束和 Task 验收通过分别记录。产品成功需要用户所需产物、可核对来源或执行回执，以及对应格式 / 内容验收；不能只看 HTTP 200 或模型说“完成”。
