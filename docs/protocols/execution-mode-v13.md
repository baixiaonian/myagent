# 执行权限模式 v13

用户通过输入区“执行权限”选择 `standard`（默认）或 `full_access`。这是任务执行配置，不是模型工具参数。SQLite 当前 v13，聊天 SSE 仍兼容 v1–v6。

## 请求与持久快照

发送 `/api/v1/sessions/:id/runs` 和重新生成 `/api/v1/sessions/:id/regenerate` 的原输入增加可选 `executionMode`。缺失解释为 `standard`；其他值返回 400。模式纳入 requestId 指纹，改变模式不能复用旧请求标识。标准模式保持旧指纹兼容。

Run 的 JSON 保存模式，普通快照和运行事件一并返回；invocation 记录真实执行模式。旧 Run 字段缺失保持标准模式，不回填批准。成员由 ChatService 读取主 Run 模式，忽略成员提交的模式；恢复沿用已保存 Run，页面选择只作用于下一次新任务。重新生成是新 Run，使用这次明确提交的模式。

输入框旁始终展示选择，生成或暂停期间禁用切换并展示当前 Run 的模式。浏览器本地存储仅记住用户模式偏好；打开页面、选择权限不创建会话。已有暂停任务需停止后重新发起任务，不能通过切换偏好重新派发未确定的旧动作。

## 执行语义

| 检查 / 能力 | 标准权限 | 完全访问 |
| --- | --- | --- |
| 命令规则与资源 allow / prompt / deny | 按原规则执行和审批 | 跳过，不生成虚假批准或长期 grant |
| 文件目标 | 受保护路径与已授予范围校验 | 可操作当前系统用户可访问的真实路径 |
| 本地进程 | 原生沙箱；隔离探测失败拒绝 | 显式无沙箱执行，无需隔离依赖 |
| 网络 | 具体域名授权与沙箱边界 | 当前系统用户可访问的网络，包括本机服务 |
| 参数、工具版本、目录身份、文件哈希 | 校验 | 保持校验 |
| intent / receipt、日志、超时、取消、结果额度 | 保留 | 保留 |
| 未知结果核对、重新运行副作用确认 | 保留 | 保留 |

`ToolService` 从服务端 Run 构造 ExecutionContext，Registry 校验 Schema 和规范路径；完全访问提前结束权限判定，但仍经过资源锁、执行槽、派发前版本校验及意图落库。Worker 初始化冻结模式，缓存键包括模式，不存在“沙箱失败自动改裸进程”。完全访问不提升为 root，不绕过系统文件权限、macOS 隐私授权或容器挂载边界。

完全访问命令使用非登录 Shell，基础 PATH 与原工具链一致，HOME 指向服务端用户目录。主服务的密钥环境变量不会自动复制到工具进程。但无沙箱进程可以主动读取该用户可访问的凭证文件；此模式不能声称仍隔离应用数据和宿主凭证。资源锁依然协调已声明目标，不承诺任意 Shell 内部访问都能静态识别，也不保证外部程序遵守这些锁。

## MCP、Skill、Hook 与团队

- MCP 已启用、已确认的服务在 Run 准备时建立相应模式连接；HTTP 和 stdio 的连接、目录、工具名称按服务/版本/项目/模式隔离，标准任务不能复用完全访问连接。派发再次核验模式。配置禁用、撤销、OAuth 和外部配置确认仍有效，不自动安装或启用服务。
- Skill 脚本和插件工具经相同模型工具链继承 Run 模式。完全访问不再提供 OS 层面的技能副本只读保证；源版本、加载与引用仍保留。
- Hook 是用户配置的独立脚本授权，仍用自身声明的沙箱范围，显式拒绝检查仍有效。不会因模型任务选择完全访问而扩大 Hook 包的配置授权，也不会新增审批代答。
- 主 Agent 和本轮成员模式一致。一次批准不跨成员继承；完全访问依靠主任务选择，不靠复制 grant。模型不能通过 `exec_command` 参数、消息或角色说明自行选择模式。

## 迁移与验证

[0013_execution_mode.sql](../../migrations/0013_execution_mode.sql) 增加 Run 模式索引和版本门禁；复用原 Run/调用 JSON，不伪造旧授权、不执行工具、不重放请求。备份完整数据目录后升级；回退需恢复升级前数据，旧 v12 程序拒绝打开 v13。

专项入口：`tests/execution/full-access.test.ts`、命令权限测试、原生执行/MCP 测试、团队继承测试和浏览器执行测试。真实进程测试只使用临时目录和 loopback 协议替身，不以假模型证明真实模型自主性。

兼容补充：exec_command 显式 readOnly:true 表示本次命令主动选择受限执行，即使 Run 为 full_access，也使用只读 OS 沙箱。普通完全访问命令的行为不变，不自动降权；只读限制、锁范围与故障语义见 [ADR-0020](../adr/0020-readonly-execution-and-bounded-contention.md)。
