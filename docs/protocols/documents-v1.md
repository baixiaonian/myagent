# 文档工作区协议 v1

本机用户可在聊天右侧浏览已登记项目、编辑 Markdown / HTML 并保存文件。人工操作不创建 Run、Invocation 或审批，不自动调用模型；Agent 的文件操作仍遵循执行协议。SQLite v13 与 SSE v6 均不变。

## HTTP 接口

继承服务端 Host / Origin 限制，SDK 是 Web 唯一入口。

| 方法与路径 | 输入 / 返回 |
| --- | --- |
| GET `/api/v1/projects/:id/files` | `path` 默认 `.`；`offset` 十进制字符串。返回当前目录条目及 nextOffset，每页最多 300 条 |
| GET `/api/v1/projects/:id/document` | `path` 为项目相对路径或项目内绝对路径；返回 path、format、content、revision、bytes |
| PUT `/api/v1/projects/:id/document` | path、content、expectedRevision；返回本次保存版本。不自动重试 |

revision 为原 UTF-8 字节 SHA-256。读取和未编辑保存保留 BOM / CRLF。支持 `.md` / `.markdown` / `.html` / `.htm`，最多 1 MiB；拒绝无效 UTF-8、二进制及特殊文件。目录惰性展开，略过 `.git` / `node_modules`，其他文件只列名称；符号链接不跟随。

项目必须存在且身份仍有效。所有目标必须在该项目内，并经过受保护路径检查。人工操作与模型工具、Hook 使用同一 ExecutionCoordinator：读取共享项目锁，保存排他项目锁，超时返回 resource_busy，不能释放其他任务持有的锁。未知结果涉及该项目时拒绝保存，读取可用于核对。

适配器复核原哈希，写入同目录临时文件、sync 后再次复核路径和哈希，再原子 rename。并发保存只有持有最新版本者成功。外部进程不受应用锁约束，不能声称完全消除宿主 TOCTOU 竞态；可信本机单用户边界保持。

## 前端状态

点击回答中的 Markdown/HTML 内联路径或本地 Markdown 链接打开右栏。代码围栏内的代码保持纯文本。右栏包含文档标签、项目树、可调整宽度和全宽模式；团队侧栏与文档侧栏互相切换，不停止团队运行。

再次点击对话文件引用时，干净标签读取磁盘新版本；请求期间的新草稿和保存结果优先保留。草稿按项目和文件存于当前页面内存，所有打开标签的保存队列常驻；切换标签、项目或收起面板不取消保存。刷新触发未保存离开提示，不声称重启恢复草稿。

Markdown 只有一个可读写画布，输入 Markdown 标记即时渲染，不再划分阅读、编辑和源码模式。Tiptap 提供标题、加粗、斜体、删除线、列表、任务、引用、链接、代码块、表格、撤销和重做。打开、阅读和选中均不序列化；实际编辑可能规范化 Markdown 空行及分隔符。front matter、原始 HTML、注释、脚注、引用定义等不支持的片段在同一画布内作为原文代码块保留，写回时去掉内部包裹；普通正文继续富文本编辑。外部图片不加载。

自动保存等待输入停顿 650ms，中文组合输入结束前不提交；同一文档串行 CAS，保存期间的新输入跟随已确认版本继续提交。标签栏右侧显示等待/正在保存/已保存或错误状态，并保留刷新入口；完整路径通过标签悬停提示查看，不单独占行；Cmd/Ctrl+S 可立即刷新保存队列。关闭文档标签先等待最后一份草稿保存，失败保留标签；刷新读取期间的新输入不能被迟到响应覆盖。

自动保存失败后停止自动重试，修改留在页面，用户可点击重试。版本冲突展示磁盘与草稿双版本并暂停自动保存；用户显式采用磁盘内容，或选择以新版本为基线保存自己的内容，均继续保留 CAS 检查，不能忽略后来再次出现的冲突。

HTML 默认打开「交互预览」：保留内嵌 JavaScript、事件处理、样式及数据，让报表初始化、月份筛选和动态图表真实运行。外部脚本、样式、接口和项目相对资源暂不加载；支持自包含单文件 HTML，不声称等价于开放网络的完整浏览器。

预览采用两层无同源权限的 sandbox iframe：可信外层只创建 Blob 页面并限制 `frame-src blob:`，防止文档通过自身导航访问 HTTP 接口；内层 CSP 允许内嵌脚本和 data/blob 图片，禁止连接、嵌套页面、Worker、表单及外部资源。没有弹窗、顶层导航、下载或宿主同源权限。纯 parse5 解析不预加载资源，原始 CSP、base、跳转元数据和外部脚本在副本中移除。内层不能修改外层策略，父应用不接收运行页面的选区或保存消息。Blob 随承载页面释放；预览 DOM 和筛选状态不写回文件。

「文字编辑」保留原静态选区方案：移除原脚本和事件处理，仅执行 nonce 选区桥；核对 iframe 身份、内容令牌和源文偏移，支持单文本节点加粗/斜体和跨节点引用。切换模式卸载旧 iframe、清空选区，只有静态编辑模式接受选区消息；返回预览重新运行原文。原始脚本始终保留在文件中，局部格式修改不把整份 HTML 重新序列化。Markdown 仍只有一个读写画布，不增加模式切换。

选中文本后在选区附近仅显示「添加到对话」浮层，滚动、切页、点击外部或 Escape 收起；重新选中相同范围仍可操作。已移除浮层编辑入口和替换表单，不提供独立 AI 选段编辑提交。Markdown 正文仍可直接输入并自动保存。

「添加到对话」产生独立于输入文字的「N 个已选文本片段」芯片，可展开查看路径/原文和逐项移除。片段随会话草稿隔离，新增对话创建后迁移到实际会话；用户发送时才将文件路径、项目身份、读取版本、选区原文及未保存标记组合到既有消息 content。保留原输入、不自动发送、不自动授予工具权限；发送成功只清理本次携带的片段，失败保留草稿和片段。组合内容仍受既有 8000 字符输入边界约束，不承诺模型仅修改选段。

## 依赖与验证

Web 使用 Tiptap 3.31.3 与 parse5 8.0.0；单页编辑已移除 CodeMirror 及语言包依赖。这些依赖均为 MIT（参照 [Tiptap Markdown 官方接口](https://tiptap.dev/docs/editor/markdown/getting-started/basic-usage) 与本地锁定版本），通过官方 npm 固定版本安装，无云编辑服务或额外账号；重编辑器按需载入。相关测试位于 `tests/documents`、`tests/e2e/documents.spec.ts`。设计边界见 [ADR-0021](../adr/0021-document-workbench.md)。
