# 项目选择与 MCP 配置

项目是对话的真实工作目录。用户在新对话输入框上方选择本机文件夹，后台登记并在首次发送时绑定；不选择则分配独立默认目录。没有单独创建“项目空间”的前置步骤。

## 项目与目录

`ProjectService` 协调项目准备、创建幂等和旧会话补充绑定。`LocalProjectDirectories` 负责文件系统与原生目录窗口，`LocalWorkspace` 仍负责真实路径、目录身份及保护边界。macOS 使用固定的 `choose folder` 脚本，Linux 桌面使用 Zenity；无桌面、Docker 或不可用时返回明确状态，页面提供目录浏览/路径输入。

默认根目录为 `~/MyAgent/Workspaces/`，由 `MYAGENT_WORKSPACE_ROOT` 覆盖。每次创建请求使用稳定分配标识的摘要作为子目录名，不把用户提供的 requestId 当成文件路径。真实目录准备在数据库事务之外；会话、工作区关联和创建请求记录同事务提交。取消选择不创建会话。显式重新选择同一路径时，仅复用身份一致的工作区；身份变化则登记新 ID，保留旧会话/授权/信任记录，执行层仍严格校验旧身份。最近项目按路径展示最新登记，完整旧记录仍保留。删除会话保留文件及创建请求墓碑，重试不能复活被删除的会话。

目录与数据/凭证目录分离。Docker 默认工作区位于 `/workspaces` 独立卷。已有会话不改变工作目录；旧未绑定会话在用户下一次提交时补充分配，不改写旧执行历史。

## MCP 配置的唯一来源

用户级配置位于数据目录的 `mcp.json`，项目级位于 `<项目>/.myagent/mcp.json`。表单、JSON 编辑器和外部编辑器使用同一个文件。SQLite 的 connections 是执行投影，mcpFiles 保存应用版本、信任版本和提交日志，不提供绕过文件的第二个公开写入入口。

文件结构为 `mcpServers`。项目级同名条目整体覆盖用户级，禁用的项目条目也遮蔽用户条目。旧版 workspaceIds 限制保留，迁移不会扩大授权。秘密只通过连接内逻辑槽位引用，不能借同名条目从另一作用域获取秘密。

配置写入先校验并准备独立凭证引用，再持久化提交日志，随后按文件哈希校验、临时文件 fsync 和原子 rename，最后应用连接投影。若文件已落盘而响应失败，保留日志和引用；重启通过实际文件内容核对后完成提交。外部编辑器不遵守本应用锁，最终检查与 rename 之间仍存在普通文件系统竞态，不宣称跨进程强事务。

外部项目配置首次出现或发生变化，暂停相应服务的新派发并显示待确认。确认绑定具体哈希；模型写文件不能确认自己的配置。用户级无秘密的新文件改动自动应用；含明文认证材料时先要求转换。非法 JSON 返回安全行列位置，不回显原始文本；用户级保留上次有效配置，项目级暂停受影响服务。

## 连接与工具目录

`McpManager` 负责按项目加载、覆盖、确认、激活和管理视图；`McpRuntime` 使用官方 MCP SDK/受限 stdio Worker 实现握手与调用。客户端、运行状态和注册目录按服务身份、配置版本、工作区区分。

每个服务用 `toolExposure` 选择定义提供方式，缺省为 `deferred`：模型通过 search_tools 按需加载，在同一会话的后续 Run 中复用仍有效的定义。`direct` 服务在每次模型请求前直接提供其已发现的全部工具定义，不占用搜索每次最多 5 个或已加载定义 16,000 字符的预算。两种方式同样检查项目、启用、信任及定义版本；直接提供也需要经过真实执行审批。整体上下文预算继续生效，超限明确报 context_limit，不自动切换为按需或静默丢工具。配置变更沿既有版本应用与断连路径处理，新的提供方式从下一次模型快照生效。决定见 [ADR 0007](../adr/0007-mcp-tool-exposure.md)。

`McpToolSelection` 在应用层维护会话选择与 Run 副本：只持久化工具名称、定义版本、连接身份/版本和字符预算，不复制完整定义。新 Run 创建时继承，随后每次请求与当前注册表、项目和配置核对。暂时断连的引用保留但不可见；重新握手且版本一致后恢复。禁用、待确认、权限范围或版本变化使旧引用不能使用。定义从注册表重新读取，缓存不作为连接状态或授权事实。详情见 [ADR 0008](../adr/0008-session-tool-selection.md)。

没有会话时，MCP 设置使用独立 `.mcp-check` 检测目录。该目录允许握手和工具发现，业务 tools/call 被拒绝。实际任务使用自己的项目实例，不复用检测目录下的工具调用上下文。

页面约每 2 秒读取状态；服务端约每 1 秒检查已激活上下文的配置文件，已连接服务最多每 15 秒检查一次目录。目录通知及时更新注册表。已连接必须来自当前运行时握手和目录获取，不继承重启前的状态字段。工具显示已发现/当前可用，不存在独立的“工具网络连接”。

新增/保存后自动连接有效服务，每个配置版本/项目自动尝试一次；错误后由用户重新连接，避免不断启动失败进程。OAuth 返回后保留同一项目上下文。配置应用、禁用、删除及授权撤销取消对应实例；取消与 unknown 仍走现有工具事实和核对路径，不自动重放 tools/call。

## 模块与后续扩展

主链路不变：Web → SDK → Application → Kernel Loop → ToolService/Registry → Runtime/Worker。目录选择属于用户管理入口，不暴露为模型可调用的任意命令接口。

协议见 [项目与 MCP v4](../protocols/projects-mcp-v4.md)，使用说明见 [项目与 MCP 设置](../development/projects-mcp.md)，决策见 [ADR 0006](../adr/0006-projects-and-mcp-config.md)。没有新增 Agent 框架、MCP 广场、单工具开关或桌面壳。
