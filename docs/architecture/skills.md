# Skill v1

Skill 是按需加载的任务说明与资源包。模型决定是否使用；唯一 Agent Loop 仍只负责上下文、模型、工具和反馈。

[查看实现原理图](../../diagrams/skills.svg) · [图中职责与源码对照](../../diagrams/README.md)

## 运行链路

1. ChatService 创建 Run 时冻结目录、主说明版本和显式选择；用户消息/Run/选择共用事务，选择 ID 进入提交指纹。
2. ContextService 在首次请求前加载显式选择；目录按可用输入预算 2%（最多 4000 估算 token）提供。完整目录可用 search_skills 分页查询。
3. 模型调用 load_skill 时先生成包候选；完整回执存储成功的事务中才发布激活。失败/取消/迟到结果不能发布。
4. 每次准备上下文单独注入一份本轮主说明，使用带来源的 user 消息，不提升为 system 指令。正文不通过工具 8000 字符预览，也不进入历史压缩块。
5. 参考资料经 read_skill_resource 读取；脚本、模板经原有工具使用。下一 Run 不继承活跃列表，但历史中的实际使用记录保留。

## 版本与文件

用户来源默认 ~/MyAgent/Skills；项目来源为根目录 .myagent/skills。可登记用户级或项目级额外目录；集合只扫描直接子目录，也可登记单个包。同名不合并，按来源生成稳定 ID。文件变更和启停从下一 Run 生效。

YAML 使用固定 yaml 2.8.2（ISC，无安装脚本），core Schema，拒绝别名展开、自定义类型和重复 key。name/description 遵循标准；openai.yaml 的隐式开关与展示信息可读取，依赖只提示，allowed-tools 不赋权。

SKILL.md 默认最多 64 KiB；文件 20 MiB、包 100 MiB、文件及目录项 10000，可通过环境变量调整后快照使用。捕获复核目录身份、文件内容和清单；拒绝包内链接与特殊文件，忽略 .git 管理目录。超限或变化明确失败。

快照保存到数据目录 skill-packages，以包内容哈希命名。运行副本在系统临时目录的实例私有 myagent-skills-* 下，按哈希稳定定位；缺失时从持久包重建，已被修改时拒绝执行。源文件不因接入、移除或会话删除而修改。

## 权限与恢复

应用层只为当前 Run 激活包提供可信只读路径；注册表把路径计入准备资源和指纹，Policy 在显式拒绝之后允许此只读范围。Worker 增加明确 denyWrite，不会因父目录可写而放开包写入。

脚本依旧走 exec_command，默认工作目录是项目，解释器仍需命令规则/本次审批，额外写入与网络仍需资源授权。不会把应用数据目录传入沙箱读白名单。

取消等待用统一 abortable：不合作的文件端口无法阻塞 Run 终结或迟到激活。恢复复用原包；网关派发前也恢复只读副本，使暂停中的工具批次无需再次请求模型即可安全继续；重新生成继承原问题显式选择并按当前有效目录加载独立快照。技能必要内容超限进入 waiting_context；用户可应用新容量，不靠裁剪技能修复。

SQLite v8 保存来源、启停、Run 目录/激活及包引用。文件先发布，数据库再引用；启动清理未引用暂存/包。会话删除级联清理 Run 引用，存在活动进程或未解决副作用时延迟包回收。旧版本历史无技能字段时保持原显示。

模块入口见 [模块关系](modules.md)，API 见 [v8 协议](../protocols/skills-v8.md)，使用见 [维护说明](../development/skills.md)。
