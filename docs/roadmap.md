# 下一步开发入口

以下均为候选迭代，未在骨架初始化中实施。

1. 最小对话闭环：先定义命令 / 事件 / Session / Run 边界，再接一个模型、应用命令和工作台流。验收包含请求幂等和断流处理。
2. 一个真实工具：完整参数 → 最终校验 → Policy → Execution → 回执 → 下一步。验证拒绝、取消和结果未知。
3. 内容闭环：上下文预算、Skill 按需加载、产物登记和来源引用。
4. 长任务可靠性：持久等待、进程恢复、工作区一致性与任务验收。
5. 编排与扩展：固定工作流、定时 / 后台任务和子 Agent，复用既有权限、预算及持久化。

每轮具体范围由用户任务决定。涉及核心边界变化时先记录 ADR，保持工程、文档与当前状态一致。
