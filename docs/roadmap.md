本地 Web Chat v1 已实现，当前验收边界见 [STATUS](STATUS.md)。真实 DeepSeek 多轮问答及 Docker 构建 / 卷恢复已完成，详见 [补充验收](history/2026-09-08-live-model-and-docker-acceptance.md)。后续按目标部署平台补充其他架构 / 服务商兼容验证。

后续候选范围由用户任务决定：

1. 改善本地产品：可控导出、历史管理、更多模型适配器与兼容评测。
2. 工具闭环：完整参数 → 最终校验 → Policy → Execution → 回执 → 下一步，测试拒绝 / 取消 / 未知结果。
3. 内容闭环：Skill 按需加载、上下文预算、产物登记和来源引用。
4. 长任务：持久等待、工作区一致性与明确任务验收。
5. 编排与扩展：Workflow、定时 / 后台、子 Agent，复用已有状态、权限和预算。

公网、多用户是单独产品决策，必须先设计认证、配额、数据隔离，不能直接对外暴露当前本机服务。
