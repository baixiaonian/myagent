# ADR-0014：插件组合既有能力并固定 Run 版本

日期：2026-09-28。状态：已采纳。

插件需要成套安装、更新、回退及卸载，但不能引入另一个 Agent Loop 或后端主进程任意模块加载。

采用 Skill/MCP/Hook 组件提供者、不可变内容寻址包、预览确认与作用域绑定。项目覆盖的是同一来源插件的状态/版本，不合并认证信息。不同来源的同名包保持独立。手工配置文件不承载插件投影。

Run 固定一个版本集合，三类能力共同使用；MCP 连接同时隔离包版本、组件配置和工作区。选择修改全局 MCP 配置、只固定 Skill 文本会导致旧 Run 误用新工具，因此不采用。

Git 只读对象，禁用宿主配置/认证助手/交互和仓库执行步骤，不 checkout、不安装依赖。跨生态组件逐项兼容，不猜测 Hook 映射。代价是部分外部包需要适配，不能声称完整支持 Codex 全部插件。

保留旧包直至可恢复任务、活动进程及未知结果释放；卸载保留源文件、产物和执行历史。迁移只建立管理结构，无隐式联网和执行。
