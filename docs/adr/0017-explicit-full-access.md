# ADR-0017：显式选择、按 Run 冻结的完全访问

日期：2026-09-29；状态：已采纳。

用户希望本机可信任务能自主执行文件、命令和 MCP 工具，不被逐次审批打断。

选择新增 `standard / full_access` 两种 Run 模式；默认标准，完全访问由输入区显式选择，创建时持久化并由成员继承。完全访问跳过命令规则和资源审批，执行进程不使用 MyAgent OS 沙箱。它不是批准按钮自动点击，也不是隔离失败的回退。

不修改 Agent Loop；变更收敛在 ChatService 快照、ToolService 权限分支和 Worker / MCP 适配器。Worker 与 MCP 连接和目录按模式隔离，取消、时间/输出额度、版本校验和未知结果治理保持。Hook 配置授权独立，不因模型工具模式改变。

后果：完全访问具有服务端系统用户的文件和网络权限，可能访问应用数据和宿主凭证；标准模式的保护保证不能套用到它。容器中仍只能访问容器自身可见资源。基础环境仍经过显式构建，HOME 使用真实用户目录，不自动传播主服务密钥环境。

未采用“只跳过审批但保留原沙箱”，因为会把完全访问误表示为仍需逐路径和网络放行的模式；未采用全局运行中修改，因为会让已批准/暂停的任务和成员产生不一致权限。用户需停止原任务再以新模式重新发送。

协议见 [执行模式 v13](../protocols/execution-mode-v13.md)。新增 SDK 兼容字段，不增加模型工具或第二套循环。
