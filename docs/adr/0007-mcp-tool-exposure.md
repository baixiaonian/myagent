# ADR-0007：由用户按 MCP 服务选择工具提供方式

- 日期：2026-09-22
- 状态：已采纳；Run 内复用边界由 [ADR 0008](0008-session-tool-selection.md) 扩展为会话内复用。

## 问题

原实现对全部 MCP 工具统一按需加载。工具数量较少或经常使用的服务因此也需要模型先执行搜索。仅按工具总数自动决定加载方式，不能表达用户对不同服务的偏好。

## 选择

在双作用域 mcp.json 的服务条目中增加 `toolExposure: deferred | direct`，默认 deferred。设置表单与文件共同维护该字段；项目级同名配置整体覆盖。ToolService 在模型请求前组装基础工具、有效 direct 服务全部工具和本 Run 已加载的 deferred 工具。Loop 与两种模型适配器保持原通用协议。

direct 仅改变定义可见性，不改变连接、信任、Schema 校验、审批、调度和副作用语义。旧配置与旧记录省略字段均保持按需。配置方式变更沿原版本应用流程处理，不能让旧版本调用继续派发。

## 替代方案与后果

- 不采用按工具数量强制自动选择；用户显式配置更可预测。
- direct 不套用搜索每次 5 个和 loadedTools 16,000 字符预算；整体上下文预算仍限制请求，超限明确失败，不静默切换策略或裁剪工具。
- 本次不改变 deferred 的 Run 内复用边界，不增加跨消息缓存、单工具开关或新的搜索算法。
- SQLite 连接以 JSON 保存，可兼容追加字段，数据库版本仍为 v4。旧客户端更新连接时省略该字段保留既有选择。
