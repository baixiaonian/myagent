# ADR-0016：本地追踪、独立账本和原始 HTTP 采集

状态：已采用，2026-09-29。

## 决定

1. 沿用单一 Loop。显式 ObservationScope 穿过模型排队及摘要包装；业务用例和适配器记录实际事件，不引入额外推理、重试或降级。
2. 用量账本独立于 Trace 和正文保留期。以实际网络请求为唯一费用单位，缺少信息保持未知；定点计算和价格快照保证可解释、可重现。
3. 原始材料在 SDK fetch 边界取得，与结构化视图分离。默认不开启，原样保存正文，凭证头不采集；私有续接仅在独立本机调试接口获得明确例外，不扩大普通历史/工具/日志边界。
4. SQLite 有界诊断队列、受保护正文文件、可选 OTLP 适配器组成模块化单体的观测实现。后台断链和采集故障不改变业务结果；账本失败阻止新付费请求。
5. 同进程审批与团队等待保留主链路，以等待 Span 记录；持久暂停或重启恢复使用新的执行段和 Link，不重新打开已结束 Span。页面按主任务归组，成员通信使用因果 Link。并行工作量与总历时分开，避免相加误导性能判断。

## 取舍

不上线独立的 Trace 服务，不把模型上下文交给外部观测后端。JSON/SSE 原文不被脱敏预览替代，因此调试文件包含真实工作资料；采取显式开关、本机访问、文件权限、容量和保留期约束。价格条件无法核实时不计算，而非假装准确费用。
