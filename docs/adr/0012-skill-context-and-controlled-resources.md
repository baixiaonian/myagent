# ADR-0012：Skill 渐进上下文与受控只读资源

日期：2026-09-26。状态：已实现，验证证据见本轮历史。

## 选择

- Skill 由模型自行使用，不增加专用 Loop、强制步骤或选择模型。目录先加载，主说明按需完整注入，资源按需读取。
- 用户级与项目级独立目录，可登记外部来源。同名不自动覆盖，ID 带来源。
- 本轮激活正文不可压缩，新一轮不自动继承。普通工具的 8000 字符结果上限不适合作为技能主说明载体，因此 load_skill 只返回引用，ContextService 独立注入完整正文。
- 采用源文件与内容寻址包快照分离，当前 Run 使用只读副本；文件变化和启停下轮生效，避免旧说明配上新脚本。
- 包内只读是用户接入来源后允许的资料读取范围；执行脚本仍走命令规则/资源审批/沙箱，元信息不赋权。
- extensions 提供纯协议与选择，application 协调，adapters 提供文件/YAML/快照。增加两条显式依赖边，不将文件系统放入 Kernel。

## 未采用

整库正文常驻会浪费输入空间；将正文作为普通工具结果会截断关键规则；跨 Run 自动继承容易影响无关任务；主服务直接执行脚本会绕过治理。首版不附带 Git 安装、技能市场和第二套审批。

## 后果

快照增加有限本地存储，需要引用回收；正文过大可能进入 waiting_context。原文件和依赖仍由用户维护，不承诺任意其他产品 Skill 无修改可运行。
