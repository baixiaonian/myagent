# ADR 0011：可追溯的两阶段长期记忆

状态：已采用。日期：2026-09-26。

原始历史与上下文摘要解决当前会话续接，长期记忆解决跨会话复用。两者不共用独立会话笔记，不把压缩摘要直接提升为长期事实。

选择 Markdown 作为知识正文来源，SQLite 保存可重建索引、任务、来源和提交日志。MemoryService 串行发布，恢复先核对文件；后台阶段直接调用 ModelPort 且禁止工具，不增加新的 Agent Loop、子 Agent 或向量数据库。

用户显式开启后才自动处理新内容；首次开启水位限制回溯，历史补录须手动选择。前台优先、调用前预占额度、失败不自动重发。模型只生成候选，来源身份、版本、人工保护、删除排除和实际发布由程序决定。

概览按完整条目预算化，每 Run 冻结，按需工具查阅详细来源。普通更新下个 Run 生效，删除/禁用在下一准备边界撤销旧独立片段。记忆是有时效的历史资料，不是项目规则或执行授权。

代价：纯文本检索的语义召回有限，模型提炼仍需用户核实；单正文文件有 4 MiB 上限，任意外部编辑器不参与事务。保留可替换的 MemoryProvider/MemoryFiles/MemoryStore 端口，未来可以迁移分片正文与索引，不修改核心循环。
