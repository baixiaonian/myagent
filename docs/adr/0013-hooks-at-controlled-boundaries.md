# ADR-0013：固定生命周期 Hook 与配置时授权

状态：采用。日期：2026-09-28。

## 决策

保持唯一自主 Loop。Hook 只接入 RunStart、PreToolUse、PostToolUse、RunEnd，应用层协调有限控制结果；不增加模型评价或结束后续跑。

Hook 为本地不可变脚本包，授权绑定配置、包哈希和资源。复用 Skill 内容快照；复用执行 Worker、槽位、锁与回执，但使用默认项目只读的权限配置，禁止继承工具的工作区写权限。脚本参数数组启动，事件从标准输入传入。

有匹配 Hook 的工具批次串行，无匹配维持已有并发；同事件按用户级、项目级文件顺序执行。调用前失败默认拒绝，调用后失败仅警告，未知真实副作用始终隔离。Hook 自身不触发工具 Hook。

Run 快照与 cleaning 待提交结果持久化。重启只核对回执，不自动重做副作用、不补造模型 Step。外部删除已生效检查也需要确认，不能静默放行。

## 取舍

首版不支持参数改写、审批代答、远程 Hook、后台运行或 Stop 续跑，避免 Hook 演变为第二套执行流程。完整包重新核验增加启动 I/O，但本机单用户可以获得明确版本与授权边界。原子文件替换和哈希校验无法代替整个宿主文件系统事务。
