# ADR-0021：人工文档工作区与原文保存

状态：已采纳。

用户需要从回答中的交付文件直接阅读、修改，并带选区继续提问。聊天 Markdown 渲染器不具备文件版本、编辑状态和项目身份，不能直接改造成文件写入入口。

采用独立 DocumentService 和 DocumentFilePort，由 Server 装配，SDK 提供严格 API。人工编辑属于用户显式本机文件操作，不创建第二套模型循环；与工具共用资源锁、路径身份、受保护目录与未知结果隔离。读取版本使用原始内容哈希，冲突保留草稿，禁止静默覆盖。

Markdown 使用单页富文本编辑，扩展语法在正文内保留原文片段，实际编辑可规范化格式。编辑自动防抖保存，关闭标签先完成串行 CAS 队列；错误保留草稿，冲突由用户选择处理。选段以独立芯片加入会话草稿，发送时再组合到既有消息协议。HTML 最初使用隔离静态预览与原文选区修改，避免把任意网页转换为富文本节点造成样式/脚本/布局丢失。现按 [ADR-0022](0022-interactive-html-preview.md) 默认提供隔离交互预览，静态方案仅用于文字编辑；不访问外部资源。目录按需读取，草稿仅存当前页面内存。

内部依赖边、数据库和聊天事件版本不变。外部编辑器不参与进程内锁，因此最终哈希复核只缩小文件系统竞态；产品继续限定可信本机单用户。详见 [文档工作区协议](../protocols/documents-v1.md)。
