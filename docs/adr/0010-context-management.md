# ADR-0010：有来源、可恢复的上下文视图

日期：2026-09-26。状态：接受并实现。

## 决策

保留单一模型自主循环，异步上下文准备在模型请求边界执行。历史记录、每次请求视图和长期记忆分开；摘要只替换视图，不修改历史事实或权限。

双协议共用 ContextService 和无工具摘要请求。采用完整调用块与容量预算，不强制保留固定轮数，因此单轮长任务也可压缩。大结果使用有界预览和原文引用，摘要遗漏细节可通过会话内只读查询找回。

摘要模型使用当前连接快照，不增加独立模型配置。采用字节近似而不是假装精确 tokenizer；服务商实际拒绝后暂停，不自动重发。摘要失败能容纳则继续，不能则等待明确恢复。

只自动读取项目根 AGENTS.md。MemoryProvider 当前是只读空实现，不把会话摘要当作自动长期记忆。不接入向量库、外部 Agent 框架或托管 compaction API。

## 原因和取舍

原先整体保留当前 Run 会在单轮内部触顶，整轮丢弃旧历史也难以解释信息去向。来源化摘要和历史读取解决容量与可追溯问题，但摘要本身仍可能遗漏或误解，不能作为副作用、权限或任务验收的事实源。

本地完整捕获有容量边界，明确记录缺失状态比承诺无限、无损保存更真实。跨连接重建语义问答，避免重放不兼容的私有续接。

SQLite 事务发布摘要和检查点，暂停与停止复用既有 Run 状态机；不新增后台自动付费任务。后续可以替换估算器、记忆提供方和摘要策略，Loop 无需判断具体工具或业务步骤。

本决策更新 [ADR-0004](0004-autonomous-agent-loop.md) 的上下文容量策略，其自主循环与双协议边界继续有效。
