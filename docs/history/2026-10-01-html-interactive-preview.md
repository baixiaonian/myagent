# 2026-10-01：修复右侧 HTML 交互预览

## 原因与范围

用户在公开插件验收会话中打开销售报表，右侧金额为占位符、图表及明细为空。文件包含完整数据和渲染脚本；原 HTML 预览为静态选区编辑而移除脚本，导致脚本初始化没有执行。上轮只从独立浏览器验收报表，遗漏实际右栏入口。

仅修改 Web 文档工作区：默认「交互预览」运行内嵌脚本；「文字编辑」保留静态选区与格式保存。双层 opaque-origin iframe 和 CSP 防止文档访问宿主、网络及自身 HTTP 导航；交互态不注册选区桥，不写回运行后 DOM。刷新可重新运行预览。Markdown 编辑、工具权限和服务端文件协议保持原样。

## 边界与接续

支持内嵌脚本和数据的自包含 HTML；外部 CDN、接口和项目相对资源仍不自动加载，不等同于完整开放浏览器。浏览器隔离不提供 CPU/内存配额。真实报表、插件安装、模型配置不修改，不增加付费模型请求。

已检查根、apps、Web、tests 和 docs AGENTS：只更新 Web 的预览边界及测试入口约束；模块依赖、数据库和 SSE 无变化。同步 [ADR-0022](../adr/0022-interactive-html-preview.md)、[文档协议](../protocols/documents-v1.md) 与 Web 使用说明。
