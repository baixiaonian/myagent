# 2026-09-28 插件支持链路与原理图

## 目的与范围

用一张图解释安装确认、三类能力接入与版本管理。新增 PNG、SVG、可编辑 Draw.io 及共享 Python 图源；不改变产品逻辑，不安装/启用插件，不触发真实模型或业务工具。保留已有未提交修改，不提交推送。

## 核心表达

1. 本地/Git 候选经过校验与用户确认，内容哈希固定包，SQLite 保存管理状态。
2. 新 Run 固定同一份版本集合；Skill 提供操作说明、MCP 提供工具、Hook 在固定节点触发。
3. 动作仍受命令/资源权限、必要审批与原执行系统约束，Plugin 不建立第二个循环。
4. 更新/禁用/卸载改变新任务可用状态；旧引用释放后清理，不删除源文件和产物。权限撤销优先于版本快照。
