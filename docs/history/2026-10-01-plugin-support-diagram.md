# 2026-10-01 插件实现总图与服务接入位置

## 目的与范围

按用户要求用一张图解释当前系统如何支持插件。沿用安装与生效、Run 内使用、更新卸载的三层布局，明确插件管理服务和三类组件的接入位置；更新现有 PNG、SVG、Draw.io 和共享图源。仅修改图表和相关知识文档，不安装插件、不修改运行配置、不调用模型、不提交推送。

## 当前实现表达

- 清单解析和兼容/权限预览后由用户确认准确版本，PluginService 发布不可变包并登记 SQLite 管理状态；安装阶段不执行脚本。
- Run 冻结内容版本、组件选择和配置引用；SkillService 经 ContextService 提供说明，MCP Runtime 接入可调用工具，HookService 由应用层固定事件触发脚本。
- 继续使用原有 Agent Loop 与执行服务；标准模式本地动作使用沙箱，Hook 独立授权。图不声称完全访问模式存在同样隔离，也不声称本地沙箱约束远端服务。
- 更新、禁用和卸载影响新任务；旧引用释放后回收，源目录和项目产物保留，权限与凭证撤销仍生效。
