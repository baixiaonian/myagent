# 2026-09-26：项目下的会话与 Qoder 风格对话

## 目的与实现

此前侧栏将最近项目与全部历史分为两段，聊天正文仍沿用头像/作者布局，未达到用户要求。本轮通过 Computer Use 只读查看本机 Qoder 的项目树、聊天气泡、分步工具批次和输入区，按实际可见交互改造。

- Web 用完整工作区目录将会话按规范路径归组，支持折叠、选中自动展开、组内最近活动排序及项目“＋”新对话。旧目录身份只在展示上归组，绑定和权限不迁移；默认目录、未绑定、元数据缺失的会话仍可访问。
- 用户文字右侧浅灰气泡、时间与复制；助手正文无重复头像/作者。中间说明和工具批次按原 Step 顺序展示，批次/参数/结果分层展开，保留模型真实计划、状态和结果分页。
- 输入区模型入口靠右、项目入口在输入框下方。保留草稿、IME、流式、停止、滚动、审批、恢复与重新生成。

没有新增后端接口、数据库迁移、模块依赖或第三方依赖。所有历史仍来源于已有 SDK，Loop 与执行治理不变。不新增 Qoder 的未实现功能，不读取或复刻其私有源码。
