# Trace 独立链路页与右侧详情

## 目的与参考

用户指定 TPP 调用链时间轴作为交互参考：独立地址、Span 层级、同一行耗时条、点击右侧详情。通过已登录浏览器实际查看参考时间轴和 RequestModule 的属性侧栏；仅借鉴展示方式，不修改线上场景或读取前端私有源码。

## 完成项

- 新增 `/traces/:traceId` Web 页面及 `?span=:spanId` 节点链接。聊天与记录列表新标签打开，保留原标签草稿，支持直接打开、刷新、前进后退及复制链接。
- 中性浅色、紧凑节点表、固定表头、统一标尺瀑布图；工具/模型/等待/上下文颜色区分，父子缩进和展开/折叠，搜索及异常筛选保留祖先路径。
- 右侧概览、属性、关联身份、因果 Link、事件；模型输入输出独立标签，保留按需原文、完整性、分页、格式化、下载和明确清理。面板可加宽，窄屏覆盖，Esc 关闭。
- 任务列表继续按主 Run 归组，每个真实执行段都有链接和切换入口，不把恢复段当成新任务。未知时间保持未知；节点耗时与并行排布不作虚假累计。
- Span/事件独立分页；直达第 200 个以后节点自动补读，轮询保留已经加载的后续页并刷新其状态；切换节点作废旧详情请求，材料正文不预取。
