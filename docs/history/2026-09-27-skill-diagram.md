## 关键表达

- 目录、正文、资源分层加载；完整说明不作为普通 8000 字符工具预览返回。
- 显式选择首请求前加载；模型通过普通 load_skill 自主激活，不新增技能专用循环。
- 当前 Run 使用版本快照，完整说明在压缩后仍保留；下一条用户消息重新选择。
- 引用记录持久保存，脚本仍经过命令/资源检查、必要审批和 OS 沙箱；工具片段及结果进入下一次上下文。
