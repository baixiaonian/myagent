## 边界与接续

只支持本机单用户。没有后台/MCP/压缩/子 Agent Hook、参数改写或结束后续跑。脚本 package 冻结不包含项目数据与宿主依赖。文件 CAS 不能承诺跨任意编辑器的强事务；进程组终止不能宣称覆盖恶意脱组守护进程。

根、application/adapters/state/extensions、server/web/worker、tests/scripts AGENTS 已同步；Kernel Loop 没有增加 Hook 分支。协议见 [v9](../protocols/hooks-v9.md)、[架构](../architecture/hooks.md)、[ADR](../adr/0013-hooks-at-controlled-boundaries.md)、[使用维护](../development/hooks.md)。

回归发现并修复：未配置 Hook 的旧未绑定会话应继续兼容；包清单字段顺序必须保持原有哈希格式；沙箱初始化失败时移除未就绪 Worker，不能误报未知进程；Hook 单次取消不得停止同 Run 的其他业务进程；最后 Step 与 cleaning 之间的崩溃恢复重建收尾意图；已知模型失败先保存业务结果再清理。另补充持久层写入失败必须暂停、不能按后置/结束警告继续派发，以及未被 Worker 接受的动作不触发 PostToolUse。Docker 首次脚本漏删新增的验收会话导致末尾数量断言失败，已补充清理并对当前代码复跑，原报告保留在 `.cache/acceptance/hooks-docker-first.json`。
