## 语义边界

- 这些分类可组合，串并行不是独立的协作架构；第七张是跨框架接入方式。
- 子 Agent 是有自身上下文和模型／工具循环的执行者，不等于一次模型请求。
- Teams 在此特指任务板与定向消息机制；群聊特指 AutoGen 风格的轮流广播，成员行动也可以包含真实工具执行。
- DSH Agent Teams 是实验模块。独立会话或进程不等于文件隔离；Handoff 跨用户回合的当前负责人由应用保存。
- 图中结果与任务是示意，不是一次真实运行的验收证据。MyAgent 的子 Agent 与 Workflow 仍未实现。
