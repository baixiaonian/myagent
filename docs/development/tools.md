# 工具使用、升级和排障

权限模式补充：本文中的命令规则、审批与沙箱保证适用于默认**标准权限**。用户可在输入框旁选择**完全访问**，新 Run 与成员免命令/资源审批并采用无沙箱工具进程；停止、超时、版本和未知结果校验仍保留。Hook 继续使用独立授权。详见 [执行模式 v13](../protocols/execution-mode-v13.md)。


在本机按 [开发环境](setup.md) 启动 MyAgent，在新对话输入框上方选择本机目录；不选择则自动分配独立默认目录。目录不能是 MyAgent 安装目录或数据目录。首次发送自动绑定，后续更换目录请新建对话。

可以直接说：“看看这个目录有什么文件，整理 README 的错别字，修改前先确认内容。”用户不需要知道工具名。是否维护计划、调用几次模型由模型自己决定。当前文件读取只支持 UTF-8；搜索正文跳过大于 1 MiB 的文件并说明，可继续分页读取。命令采用管道，没有交互式 TTY。

## 原生依赖

macOS 需要可运行的 sandbox-exec 和 ripgrep；Linux 需要 bubblewrap、socat、ripgrep 以及宿主允许的非特权用户命名空间。依赖已由固定版本 sandbox-runtime 使用。每个执行环境先跑真实功能探测；缺少依赖或内核/容器限制时拒绝执行。

```sh
# Debian / Ubuntu 宿主
sudo apt-get install bubblewrap socat ripgrep
# 工程验证（适用平台，真实创建临时文件和进程）
pnpm test:execution:native
```

不建议为了通过测试关闭宿主保护。普通产品 Docker 默认最小权限，在不允许嵌套沙箱的宿主上仍可聊天、用时间/计划工具和 HTTP MCP，文件/命令/stdio MCP 会明确不可用；原生工具应在满足条件的 macOS/Linux 宿主运行。Compose 不映射公网端口。

## 审批、停止和重新运行

工作区内普通文件动作自主执行。纯资源的跨目录或网络请求显示工具名、准确参数、资源和批准范围，选择仅一次、当前会话或工作区长期授权。命令另经过启动策略，含命令的批准只对本次生效，规则管理见 [命令权限](commands.md)。长期授权在当前项目菜单中撤销。拒绝是工具反馈，模型可以据此换方案。

等待审批时可关闭页面，后端保留待办。请求 24 小时后过期，继续时返回过期错误，不暗中执行。命令进程仍在运行时，其单进程超时继续计算；任务本身没有总时限。停止会终止受控进程组并保存部分输出，但已经完成的文件或远端修改不会回滚。

“结果需要核对”表示有动作可能发生而回执不可靠。检查文件或服务后记录自己的结论，再选择继续；记录明确区分用户判断和原服务回执。删除聊天后未解决的最小隔离记录仍可在执行面板看到。不要把反复点击重试当成核对。

带副作用的回答显示“重新运行任务”，确认后新建候选，旧结果保留到新候选成功。它基于外部系统当前状态，不恢复到上次执行前。

## MCP

左侧“MCP 服务”添加配置：HTTP 填服务地址并选择认证；stdio 填可执行文件及 JSON 参数数组，可用 `{{workspace}}` 替换当前工作区路径。环境变量以 JSON 对象单独填写，保存后清空表单；留空保留旧值，填写 `{}` 清除。禁止把 Token 填在命令参数、URL 或普通说明中。

选择用户级或项目级作用域，保存后自动连接。stdio 在沙箱中启动；外部项目配置变更先确认。OAuth 点击登录入口，完成后返回 MCP 页查看真实状态；回调超时或 state 失效时重新连接。

模型通过 search_tools 按用途加载目录，工具实际执行仍需要授权。HTTP 不自动跟随重定向，不自动重发工具；鉴权失败重新连接后由模型/用户决定下一步。服务端 OAuth 撤销不支持或失败时，本地删除仍会清除本机凭证，界面提示到服务商账号核查授权。

## 备份、升级、清理

大结果送给模型时默认保留头尾，中间标明省略内容和补读方式；命令状态/退出码单独保留。MYAGENT_TOOL_RESULT_CHARACTERS 默认 8000（字符，不是 token），包含最终预览的 JSON 包装、转义和说明；命令即时日志内部预览最多 6000 字符。上下文不足时可继续缩小，但原文件不因截断而删改。预算小到无法容纳状态与引用时会暂停，需要提高服务端工具结果字符上限；仅增加模型窗口不能解除这个独立上限，修改服务端上限需重启并新建 Run。

本轮无数据迁移。旧的头部预览有有效结果引用时可重建首尾；结果文件被手动删除时会提示不可用。结果内全文搜索尚未实现，补读继续使用现有游标分页。

1. 停止 MyAgent，备份整个 `~/.myagent/`（或 MYAGENT_DATA_DIR），包括 state.db、credentials.json、results/、execution/；工作区文件单独备份。
2. 安装依赖并构建新代码，启动时按顺序迁移到 SQLite v7；旧消息没有工具记录时按旧方式展示。
3. 恢复要整体还原，保留目录 0700、文件 0600。不要仅复制数据库；丢失回执只能按未知处理。
4. 回退旧版本需同时恢复升级前数据，不能直接用旧代码打开 v5。
5. 删除会话清理消息、结果文件和已登记 Worker 调用/进程文件；崩溃前尚未登记的孤立文件可能仍在 execution/，没有自动过期扫描。清空全部产品数据需先停服务后删除自己确认的数据目录；外部工作区不会随聊天删除。

常见错误：`sandbox_unavailable` 检查 OS 依赖；`protected_path` 改用独立工作区；`file_conflict` 重新读取；`mcp_disconnected` 在设置重新连接；`context_limit` 本轮执行链已超过字符预算，不会静默丢弃结果；`execution_storage` 检查磁盘并核对回执。当前凭证文件受权限保护但未加密。

执行环境只保留固定可信 PATH、独立 HOME/TMPDIR 和必要语言设置，不继承主服务的密钥、加载器或任意用户 PATH；Node 和系统工具链目录禁止模型写入。自定义工具程序如不在固定 PATH 中，使用绝对路径并明确配置读取范围。

## 当前项目与连接入口

当前版本使用 [项目与 MCP 设置](projects-mcp.md)：新对话选目录或自动分配，左侧 MCP 服务独立打开，已启用且确认的配置自动连接。之前分开的创建/绑定流程已收敛，权限管理入口位于当前项目菜单。

读取型 Shell 可传 readOnly:true、cwd:"子目录"，只读沙箱与锁范围一致；跨目录读取用 additionalPaths 的 read 声明。该模式无网络、不可写项目，即使当前选择完全访问也如此。普通未知 Shell 保留原权限与排他锁。resource_busy 表示动作尚未发生：查看持锁 Run/进程，通过团队消息协调；不要用 sleep 等文件。读取进程用 read_process，waitMs<=10000；等待成员用 wait_agents，timeoutMs<=120000。
